One fortune cookie line for make.fun's "Fortune Cookie for the Liquidated Trader" bounty ($2 in USDC). It opens with the classic fortune-cookie promise — you will meet a tall, dark stranger — and the stranger turns out to be your liquidation notice, arriving at 3am dressed as a lesson: the loss itself, reframed as the one date the trader cannot cancel.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
